# 15-Day React Native Plan (For a 2-Year MERN Developer)

**Target:** Become productive in React Native and able to build production apps in 15 days.
**Daily Commitment:** 5–6 hours.

## Day 1 — React Native Foundations

* Install Expo and React Native CLI
* Understand RN architecture
* Learn Core Components:

  * View
  * Text
  * Image
  * ScrollView
  * FlatList
  * Pressable
* Build:

  * Profile Screen
  * Product Card UI

**Outcome:** Can create and structure RN screens.

---
